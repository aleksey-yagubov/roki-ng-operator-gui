# Готовность к калибровочному тесту, 2026-10-01

Проверен робот 192.168.0.119 и GUI на Mac. Программная цепочка готова
к управляемому калибровочному прогону; готовность к автономному матчу не подтверждена.

## Проверки

- Runtime на CM4: 655 passed, 2 skipped. Запуск в отдельном каталоге,
  с симуляцией аппаратных действий в тестах; физические движения не запускались.
- Ещё 13 тестов калибровочных алгоритмов с SciPy выполнены на Mac.
- GUI: 76 unit/integration tests passed.
- Оконные Qt-сценарии: 29 passed, QML warnings отсутствуют. Безэкранный
  прогон не прошёл клавиатурный выбор группы параметров; обычный оконный прошёл.
- Реальная камера синхронизировалась с IMU. Основное H264-видео около 28–30 FPS.
- Одновременно получены основной поток и обработанное видео локализации.
- Второй зритель продолжил получать кадры после отключения первого.
- Отключение обработанного видео не остановило камеру и вычисление локализации.
- Детектор жёлтого цвета получил две области стоек. Это проверка цветового
  детектора, не подтверждение геометрической классификации ворот.

## Исправлено при проверке

GUI ожидал localisation.start только 1,25 секунды, хотя сервер допускает
5 секунд на вызов воркера. Под нагрузкой это давало ложный тайм-аут с неизвестным
исходом операции. Ожидание увеличено до 7 секунд; повторы UDP остаются ограниченными,
heartbeat продолжает работать. Добавлен тест ожидания и окончательного тайм-аута.
Повторная проверка с настоящими Qt/GStreamer-приёмниками прошла.

## Ограничения перед тестом

- После перезагрузки образ оставляет lo выключенным. Для внутренних сетевых
  тестов выполнено ip link set lo up. Постоянное исправление загрузки относится
  к репозиторию Buildroot; здесь оно не внесено.
- Локализация остаётся diagnostic_only, valid=false из-за неподтверждённой
  калибровки камеры относительно тела. На последних кадрах три линии и круг,
  неоднозначная гипотеза позиции; вычисление около секунды на кадр.
- Для проверки обработки использовался старый приблизительный prior. Текущие
  координаты робота независимо не измерены, точность локализации не проверена.
- Автономный режим игры не реализован: runtime предоставляет IDLE и MANUAL.
- Физические походка, удары, вставание и калибровка поворотов в этой проверке
  не выполнялись. Запись новых калибровочных значений на реальном роботе
  не проверялась; текущие параметры не менялись.

После проверки робот возвращён в IDLE, управление освобождено. Камера и
диагностическая локализация оставлены работающими для дальнейшей настройки;
приёмники тестовых потоков отключены. Для применения изменения времени ожидания
нужно перезапустить ранее открытый GUI.
