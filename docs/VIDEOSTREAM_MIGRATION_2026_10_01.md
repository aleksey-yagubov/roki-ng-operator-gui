# GUI: новый контракт камеры и передач, 1 октября 2026

GUI использует `videostream.*`, `source` и UDP-датаграммы до 1400 байт.
Старые `video.*` не отправляются. Runtime-камера запускается без `with_imu`:
IMU обязательна и синхронизируется самим runtime.

## Передачи и просмотры

В панели видео есть каталоги источников и передач с полной пагинацией.
Недоступные источники остаются видны с причиной. Определение создаётся без
адреса назначения; GUI открывает приёмник, затем передаёт порт в start/attach.
IP выбирает робот. Основной и локализационный приёмники независимы.

«Отключить мой приёмник» вызывает detach без lease. Определение остаётся
на роботе: его можно снова запустить или удалить из списка. «Остановить для
всех» требует управления. Закрытие или перенос окна — только локальное действие.
Потеря lease не отключает уже работающий просмотр. Смена run_id требует
явного повторного подключения и очистки локального приёмника.

Наблюдатель может подключиться к активной передаче. Один поток используется
несколькими операторами, каждый с собственным UDP-портом. Для runtime можно
изменить max_fps; сервер проверяет потолок output.fps. Изменение source/кодека/
геометрии выполняется созданием нового определения. Для смены кодека при
подключении к существующей передаче нужно выбрать соответствующий декодер.

## Камера

Каталог ISP загружается через camera.controls.list, по две записи на страницу.
Supported=null сохраняется как неизвестное; false блокирует редактирование.
«Применить временно» вызывает controls.set, «Сохранить камеру» — controls.save.
Freeze фиксирует измеренные значения, но оставляет их в черновике до сохранения.
Requested и measured показаны отдельно. LAB остаётся на params.* и локальном
декодированном изображении; H.264 не считается эталоном цвета.
